# Phonebook backend

Backend for the Full Stack Open phonebook (part 3). It serves the React
frontend from `dist/` and the API under `/api/persons`.

Online application: _link to be added after deployment (exercise 3.10)_

## Scripts

- `npm start` – run the server (port from `PORT`, default 3001)
- `npm run dev` – run with automatic restart on file changes
- `npm run build:ui` – build `../../part2/phonebook` and copy the build to `dist/`
